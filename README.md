# Simple Jetpack Compose Calculator 📱

A modern, sleek Android Calculator built entirely with **Jetpack Compose**. This project focuses on custom UI components, advanced animations, and a clean Material 3 design.

## ✨ Features
- **Custom Ripple Animations:** Hand-drawn canvas ripples that expand from the exact point of touch.
- **Dynamic Scrolling Display:** The input field automatically scrolls to the right as you type, ensuring the latest digits are always visible.
- **Material 3 Design:** Uses Dark Mode aesthetics with custom white-glow shadows and card elevations.
- **Mathematical Logic:** Supports basic operations (+, -, *, /) with floating-point precision.
- **Responsive Layout:** A flexible button grid that adapts to different screen sizes.

## 🛠 Tech Stack
- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture:** State-driven UI with `mutableStateOf` and `LaunchedEffect`.
- **Graphics:** `Canvas` API and `Animatable` for high-performance custom animations.
